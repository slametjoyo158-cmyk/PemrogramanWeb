Modul Interaktif

Model & Eloquent ORM di Laravel

Pelajari bagaimana Model berperan sebagai jembatan antara aplikasi Laravel dan basis data, memahami mass assignment dengan $fillable, menguasai relasi tabel (belongsTo & hasMany), serta mengoptimalkan query menggunakan Scope.

1. Apa itu Model?

Dalam konsep MVC (Model–View–Controller), Model adalah bagian yang bertugas khusus berhubungan dengan data dan database.

Konsep Sederhana

Model = Penghubung utama antara aplikasi Laravel dengan data di dalam database.

Model memungkinkan kita melakukan operasi terhadap database menggunakan Eloquent ORM tanpa harus selalu menulis query SQL secara eksplisit.

Pemetaan Tabel ke Model
tabel: users ➔ User.php
tabel: aspirasis ➔ Aspirasi.php
tabel: kategoris ➔ Kategori.php
tabel: tanggapans ➔ Tanggapan.php

2. Struktur Dasar Model Laravel

Model pada Laravel merupakan sebuah class PHP biasa yang melakukan extend terhadap class Illuminate\Database\Eloquent\Model. 

<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Kategori extends Model
{
    //
}

Penjelasan Bagian Penting:

  • namespace namespace App\Models; — Menandakan lokasi berkas fisik model berada di dalam folder app/Models.
  • use Model use Illuminate\Database\Eloquent\Model; — Mengimpor base class Eloquent Model dari framework Laravel.
  • class class Kategori extends Model — Mendeklarasikan class Kategori yang mewarisi seluruh kemampuan Eloquent ORM.

3. Konvensi Model dan Tabel Database

Secara bawaan (*convention over configuration*), Laravel secara otomatis memetakan nama class Model berbentuk Singular (Tunggal) / PascalCase ke nama tabel di database yang berbentuk Plural (Jamak) / snake_case Bahasa Inggris.

Model Class
class Kategori extends Model
Otomatis Terhubung
Database Table
kategoris
id | nama_kategori | keterangan | created_at | updated_at

Dengan terhubungnya Model dan Tabel, kita dapat langsung memanggil method Eloquent seperti berikut: 

// Mengambil seluruh data dari tabel kategoris
$kategori = Kategori::all();

4. Mass Assignment & $fillable

Properti $fillable digunakan untuk menentukan kolom mana saja pada tabel database yang diizinkan untuk diisi menggunakan fitur Mass Assignment.

Deklarasi di Model Kategori: 
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Kategori extends Model
{
    protected $fillable = [
        'nama_kategori',
        'keterangan',
    ];
}
Penggunaan dalam Controller / Logic: 
// Mengisi data sekaligus (Mass Assignment)
Kategori::create([
    'nama_kategori' => 'Fasilitas',
    'keterangan'    => 'Aspirasi fasilitas sekolah',
]);
Mengapa $fillable Penting?
Untuk keamanan aplikasi (mencegah Mass Assignment Vulnerability). Tanpa pembatasan ini, pengguna nakal bisa saja mengirimkan request HTTP yang merubah kolom sensitif seperti is_admin atau role.

5. Studi Kasus: Model Aspirasi

Mari kita tinjau penerapannya pada kasus nyata aplikasi pengaduan/aspirasi siswa. Berikut properti $fillable pada Model Aspirasi: 

<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Aspirasi extends Model
{
    protected $fillable = [
        'user_id',
        'kategori_id',
        'deskripsi',
        'lokasi',
        'foto_bukti',
        'status',
    ];
}
Contoh Pembuatan Data Aspirasi Baru:
Aspirasi::create([
    'user_id'     => 10,
    'kategori_id' => 2,
    'deskripsi'   => 'Kipas angin di kelas rusak',
    'lokasi'      => 'Ruang X PPLG',
    'status'      => 'Menunggu',
]);

6, 7 & 8. Relasi Antar-Model & Method belongsTo

Salah satu keunggulan utama Eloquent adalah kemudahannya menghubungkan tabel (Relationships). Method belongsTo() digunakan pada model tabel anak yang menyimpan Foreign Key.

Visualisasi Relasi belongsTo
tabel: users
id
▲ Foreign Key (user_id) │
tabel: aspirasis
id | user_id | kategori_id | deskripsi
1. Relasi Aspirasi ke User (Pelapor) 
public function pelapor()
{
    return $this->belongsTo(User::class, 'user_id');
}

Cara Penggunaan:

$aspirasi = Aspirasi::find(1);
echo $aspirasi->pelapor->name;
2. Relasi Aspirasi ke Kategori 
public function kategori()
{
    return $this->belongsTo(Kategori::class, 'kategori_id');
}

Cara Penggunaan:

$aspirasi = Aspirasi::find(1);
echo $aspirasi->kategori->nama_kategori;

9 & 10. Relasi hasMany & Perbedaannya

Method hasMany() digunakan pada model induk (*parent*) untuk menandakan bahwa 1 data induk memiliki banyak (*many*) data anak.

Pada Model Kategori: 
public function aspirasi()
{
    return $this->hasMany(Aspirasi::class, 'kategori_id');
}
Method Method Arti / Arah Posisi Foreign Key Contoh Konstruksi
belongsTo() Dimiliki oleh (1 Parent) Di tabel milik sendiri Aspirasi ➔ User / Kategori
hasMany() Memiliki banyak (N Child) Di tabel milik anak / lawan Kategori ➔ Banyak Aspirasi
💡 Tips Mudah Mengingat:
• Aspirasi belongsTo Kategori (karena 1 aspirasi punya 1 kategori).
• Kategori hasMany Aspirasi (karena 1 kategori bisa berisi banyak aspirasi).

11 & 12. Local Scope pada Model

Local Scope memungkinkan kita untuk mendefinisikan kumpulan kondisi query yang sering digunakan berulang kali, sehingga sintaks penulisan di Controller menjadi lebih rapi dan ekspresif.

Contoh 1: scopeStatus()

Sederhana 
// Di dalam Model Aspirasi.php
public function scopeStatus($query, $status)
{
    return $query->where('status', $status);
}
❌ Tanpa Scope: Aspirasi::where('status', 'Menunggu')->get();
✅ Menggunakan Scope: Aspirasi::status('Menunggu')->get();

Contoh 2: scopeMilikPerwalian()

Kompleks (Relationship Query) 
// Di dalam Model Aspirasi.php
public function scopeMilikPerwalian($query, $waliId)
{
    return $query->whereHas('pelapor', function ($q) use ($waliId) {
        $q->where('wali_id', $waliId);
    });
}

Tujuan Scope Ini: Membatasi agar pengguna bertipe Wali Kelas hanya dapat melihat daftar aspirasi yang dikirimkan oleh siswa-siswa yang berada di bawah perwaliannya. 

// Di Controller Wali Kelas:
$aspirasiSiswa = Aspirasi::milikPerwalian($waliId)->get();
