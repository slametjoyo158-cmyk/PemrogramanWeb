BAB 2 — OBJECT RELATIONAL MAPPING (ORM)

Menguasai Eloquent ORM Laravel pada Sistem Sarpras Sekolah

Eloquent ORM adalah implementasi Active Record Architecture pada Laravel yang memungkinkan pengembang mengoperasikan basis data MySQL menggunakan objek dan metode Pemrograman Berorientasi Objek (OOP) tanpa harus menulis perintah SQL mentah secara manual.

Perbandingan Pengolahan Data di Laravel

Lihat bagaimana sintaks pengambilan data pengaduan sarpras yang rusak ditulis menggunakan 3 pendekatan berbeda:

1. Native SQL Manual
SELECT * FROM pengaduans WHERE status = 'proses';

Rentan terhadap SQL Injection jika tidak dishitung dengan pdo bind value manual.

2. Query Builder DB Facade
DB::table('pengaduans')->where('status', 'proses')->get();

Aman dari SQL Injection, namun mengembalikan data berupa `stdClass` tanpa method relasi.

3. Eloquent ORM Rekomendasi
Pengaduan::where('status', 'proses')->get();

Mengembalikan `Eloquent Collection` dari objek Model lengkap dengan relasi antar tabel.

Anatomi Berkas Model Eloquent

Secara standar, nama Model berbentuk tunggal (*singular*) dalam Bahasa Inggris, sedangkan nama tabel di MySQL berbentuk jamak (*plural*).

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Pengaduan extends Model
{
  // Menentukan nama tabel kustom jika tidak jamak
  protected $table = 'pengaduans';

  // Menentukan kolom atribut yang boleh diisi (Mass Assignment)
  protected $fillable = [
    'user_id', 'sarana_id', 'deskripsi_kerusakan', 'foto', 'status'
  ];
}

Keamanan: $fillable vs $guarded

Laravel memiliki perlindungan bawaan terhadap celah keamanan Mass Assignment Vulnerability (peretas menyuntikkan kolom terlarang seperti `is_admin` via HTTP request).

1. White-listing ($fillable)

Mendaftarkan kolom mana saja yang **BOLEH** diisi secara langsung menggunakan metode `Pengaduan::create($request->all())`.

2. Black-listing ($guarded)

Mendaftarkan kolom mana yang **HARUS DILINDUNGI** dari input langsung. Jika `$guarded = ['id']`, maka semua kolom selain `id` boleh diisi.

Relasi Antar Tabel di Eloquent (Studi Kasus Sarpras)

1 to N (One to Many)

User -> Pengaduan

Satu Siswa/User dapat membuat banyak laporan pengaduan kerusakan.

hasMany(Pengaduan::class)
N to 1 (Inverse)

Pengaduan -> User

Satu laporan pengaduan dimiliki oleh tepat satu Siswa pelapor.

belongsTo(User::class)
1 to 1 (One to One)

Pengaduan -> Tanggapan

Satu laporan pengaduan diproses dengan satu respon tanggapan resmi petugas.

hasOne(Tanggapan::class)

Konsep & Command Migration Database Laravel

Database Version Control

Migration adalah sistem kontrol versi (*version control*) untuk basis data yang memungkinkan pengembang mendefinisikan skema tabel MySQL menggunakan sintaks PHP Fluent Builder tanpa perlu membuat tabel manual di phpMyAdmin.

Sintaks Blueprint Foreign Key

Untuk menghubungkan relasi antar tabel (contoh `pengaduans` merujuk `users` dan `saranas`), gunakan metode `foreignId()` dan `constrained()`:

$table->foreignId('user_id')
      ->constrained('users')
      ->cascadeOnDelete();
  • foreignId(): Membuat kolom unsigned big integer.
  • constrained(): Menghubungkan ke Primary Key tabel acuan.
  • cascadeOnDelete(): Otomatis menghapus data turunan jika parent dihapus.

Perintah Utama Artisan Migration

php artisan make:migration create_pengaduans_table // Membuat berkas migration baru
php artisan migrate // Mengeksekusi seluruh migration pending ke MySQL
php artisan migrate:fresh --seed // Menghapus semua tabel lalu migrasi ulang + seeding data
