Modul Interaktif Lengkap

Model, Migration & Database di Laravel

Pelajari rancangan skema database melalui Migration, perintah CLI Artisan untuk otomatisasi (Model, Migration, Seeder), proteksi $fillable, relasi tabel (belongsTo & hasMany), hingga pengujian query interaktif.

1. Apa itu Migration?

Database Migration di Laravel ibarat version control system (seperti Git) khusus untuk struktur database Anda. Migration memungkinkan tim pengembang menentukan dan memodifikasi skema tabel database menggunakan kode PHP tanpa perlu mengeksekusi perintah SQL manual di phpMyAdmin atau DBMS.

Method up()

Dijalankan saat perintah php artisan migrate dieksekusi. Berfungsi membuat tabel baru, menambahkan kolom, atau membuat indeks relasi.

Method down()

Dijalankan saat perintah rollback/reset dieksekusi (migrate:rollback). Berfungsi membatalkan perubahan (misal: menghapus tabel dengan Schema::dropIfExists).

2. Skema Migration 4 Tabel Utama

database/migrations/xxxx_xx_xx_xxxxxx_create_users_table.php Tabel Pengguna & Hak Akses 
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::create('users', function (Blueprint $table) {
            $table->id();
            $table->string('name');
            $table->string('nomor_induk')->unique();
            $table->string('password');
            $table->string('kelas')->nullable();
            
            // Enum Role Pengguna
            $table->enum('role', ['siswa', 'wali_kelas', 'waka_sarpras'])->default('siswa');

            // Foreign Key ke Wali Kelas (Self Referencing Relationship)
            $table->foreignId('wali_id')
                  ->nullable()
                  ->constrained('users')
                  ->onDelete('set null');

            $table->rememberToken();
            $table->timestamps();
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('users');
    }
};

database/migrations/xxxx_xx_xx_xxxxxx_create_aspirasis_table.php Tabel Utama Pengaduan 
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::create('aspirasis', function (Blueprint $table) {
            $table->id();
            
            // Relasi ke tabel users (Siswa Pelapor)
            $table->foreignId('user_id')
                  ->constrained('users')//Kolom user_id pada tabel aspirasis menjadi foreign key yang mengacu ke kolom id pada tabel users
                  ->onDelete('cascade'); //Jika data pada tabel users dihapus, maka semua data aspirasis yang memiliki user_id tersebut ikut dihapus otomatis.

            // Relasi ke tabel kategoris
            $table->foreignId('kategori_id')
                  ->constrained('kategoris')
                  ->onDelete('cascade');

            $table->text('deskripsi');
            $table->string('lokasi');
            $table->string('foto_bukti')->nullable();

            // Status pengaduan berantai: pending -> verified -> proses -> selesai / ditolak
            $table->enum('status', ['pending', 'verified', 'proses', 'selesai', 'ditolak'])
                  ->default('pending');

            $table->timestamps();
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('aspirasis');
    }
};
database/migrations/xxxx_xx_xx_xxxxxx_create_tanggapans_table.php Tabel Tanggapan & Perbaikan 
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up()
    {
        Schema::create('tanggapans', function (Blueprint $table) {
            $table->id();

            // Relasi ke Aspirasi yang ditanggapi
            $table->foreignId('aspirasi_id')->constrained('aspirasis')->onDelete('cascade');

            // Relasi ke Petugas (Waka Sarpras) yang memberi tanggapan
            $table->foreignId('petugas_id')->constrained('users')->onDelete('cascade');

            $table->text('isi_tanggapan');
            $table->string('foto_perbaikan')->nullable();

            $table->timestamps();
        });
    }

    public function down()
    {
        Schema::dropIfExists('tanggapans');
    }
};
Poin Penting pada Migration Relasi:
  • foreignId('user_id')->constrained('users'): Otomatis mendefinisikan Foreign Key bertipe BigInteger yang merujuk pada kolom id di tabel users.
  • onDelete('cascade'): Jika data induk dihapus, seluruh data anak yang terhubung otomatis ikut terhapus.
  • onDelete('set null'): Jika data induk dihapus, kolom foreign key anak diubah menjadi NULL (membutuhkan nullable()).

3. Perintah Artisan CLI (Model, Migration & Seeder)

Laravel menyediakan perintah perintah berbasis terminal (CLI Artisan) untuk membuat file komponen secara otomatis serta mengelola eksekusi database migration dan seeding data.

A. Perintah Membuat Model, Migration & Seeder

1. Paket Lengkap Sekaligus (All-in-One) 
php artisan make:model Aspirasi -mfs

Membuat Model Aspirasi sekaligus berkas -m (Migration), -f (Factory), dan -s (Seeder).

2. Model + Migration Saja 
php artisan make:model Kategori -m

Membuat Model Kategori beserta berkas migration create_kategoris_table.

3. Membuat Migration Spesifik 
php artisan make:migration create_tanggapans_table

Membuat berkas migration baru secara independen di folder database/migrations.

4. Membuat Seeder Spesifik 
php artisan make:seeder UserSeeder

Membuat berkas seeder baru untuk mengisi data dummy awal di folder database/seeders.

B. Perintah Menjalankan Migration & Seeder

Perintah Artisan CLI Fungsi & Kegunaan
php artisan migrate Menjalankan semua migration baru yang belum dieksekusi ke database.
php artisan migrate:fresh Menghapus seluruh tabel database (drop all) lalu merunning ulang seluruh migration dari awal.
php artisan migrate:fresh --seed Menghapus ulang semua tabel, migrasi dari awal, lalu otomatis mengeksekusi Seeder (DatabaseSeeder).
php artisan migrate:rollback Membatalkan (rollback) eksekusi batch migration terakhir.
php artisan db:seed Menjalankan kelas utama DatabaseSeeder.
php artisan db:seed --class=UserSeeder Menjalankan Seeder Spesifik tertentu tanpa mengeksekusi seeder lainnya.

4. Apa itu Model?

1. Apa itu Model?

Dalam konsep MVC (Model–View–Controller), Model adalah bagian yang bertugas khusus berhubungan dengan data dan database.

Konsep Sederhana

Model = Penghubung utama antara aplikasi Laravel dengan data di dalam database.

Model memungkinkan kita melakukan operasi terhadap database menggunakan Eloquent ORM tanpa harus selalu menulis query SQL secara eksplisit.

Pemetaan Tabel ke Model
tabel: users ➔ User.php
tabel: aspirasis ➔ Aspirasi.php
tabel: kategoris ➔ Kategori.php
tabel: tanggapans ➔ Tanggapan.php

5. Struktur Dasar Model Laravel

Model pada Laravel merupakan sebuah class PHP biasa yang melakukan extend terhadap class Illuminate\Database\Eloquent\Model. 

<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Kategori extends Model
{
    //
}

Penjelasan Bagian Penting:

  • namespace namespace App\Models; — Menandakan lokasi berkas fisik model berada di dalam folder app/Models.
  • use Model use Illuminate\Database\Eloquent\Model; — Mengimpor base class Eloquent Model dari framework Laravel.
  • class class Kategori extends Model — Mendeklarasikan class Kategori yang mewarisi seluruh kemampuan Eloquent ORM.

6. Konvensi Model dan Tabel Database

Secara bawaan (*convention over configuration*), Laravel secara otomatis memetakan nama class Model berbentuk Singular (Tunggal) / PascalCase ke nama tabel di database yang berbentuk Plural (Jamak) / snake_case Bahasa Inggris.

Model Class
class Kategori extends Model
Otomatis Terhubung
Database Table
kategoris
id | nama_kategori | keterangan | created_at | updated_at

Dengan terhubungnya Model dan Tabel, kita dapat langsung memanggil method Eloquent seperti berikut: 

// Mengambil seluruh data dari tabel kategoris
$kategori = Kategori::all();

7. Mass Assignment & $fillable

Properti $fillable digunakan untuk menentukan kolom mana saja pada tabel database yang diizinkan untuk diisi menggunakan fitur Mass Assignment.

Deklarasi di Model Kategori: 
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Kategori extends Model
{
    protected $fillable = [
        'nama_kategori',
        'keterangan',
    ];
}
Penggunaan dalam Controller / Logic: 
// Mengisi data sekaligus (Mass Assignment)
Kategori::create([
    'nama_kategori' => 'Fasilitas',
    'keterangan'    => 'Aspirasi fasilitas sekolah',
]);
Mengapa $fillable Penting?
Untuk keamanan aplikasi (mencegah Mass Assignment Vulnerability). Tanpa pembatasan ini, pengguna nakal bisa saja mengirimkan request HTTP yang merubah kolom sensitif seperti is_admin atau role.

8. Studi Kasus: Model Aspirasi

Mari kita tinjau penerapannya pada kasus nyata aplikasi pengaduan/aspirasi siswa. Berikut properti $fillable pada Model Aspirasi: 

<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Aspirasi extends Model
{
    protected $fillable = [
        'user_id',
        'kategori_id',
        'deskripsi',
        'lokasi',
        'foto_bukti',
        'status',
    ];
}
Contoh Pembuatan Data Aspirasi Baru:
Aspirasi::create([
    'user_id'     => 10,
    'kategori_id' => 2,
    'deskripsi'   => 'Kipas angin di kelas rusak',
    'lokasi'      => 'Ruang X PPLG',
    'status'      => 'Menunggu',
]);

9. Relasi Antar-Model & Method belongsTo

Salah satu keunggulan utama Eloquent adalah kemudahannya menghubungkan tabel (Relationships). Method belongsTo() digunakan pada model tabel anak yang menyimpan Foreign Key.

Visualisasi Relasi belongsTo
tabel: users
id
▲ Foreign Key (user_id) │
tabel: aspirasis
id | user_id | kategori_id | deskripsi
1. Relasi Aspirasi ke User (Pelapor) 
public function pelapor()
{
    return $this->belongsTo(User::class, 'user_id');
}

Cara Penggunaan:

$aspirasi = Aspirasi::find(1);
echo $aspirasi->pelapor->name;
2. Relasi Aspirasi ke Kategori 
public function kategori()
{
    return $this->belongsTo(Kategori::class, 'kategori_id');
}

Cara Penggunaan:

$aspirasi = Aspirasi::find(1);
echo $aspirasi->kategori->nama_kategori;

10. Relasi hasMany & Perbedaannya

Method hasMany() digunakan pada model induk (*parent*) untuk menandakan bahwa 1 data induk memiliki banyak (*many*) data anak.

Pada Model Kategori: 
public function aspirasi()
{
    return $this->hasMany(Aspirasi::class, 'kategori_id');
}
Method Method Arti / Arah Posisi Foreign Key Contoh Konstruksi
belongsTo() Dimiliki oleh (1 Parent) Di tabel milik sendiri Aspirasi ➔ User / Kategori
hasMany() Memiliki banyak (N Child) Di tabel milik anak / lawan Kategori ➔ Banyak Aspirasi
💡 Tips Mudah Mengingat:
• Aspirasi belongsTo Kategori (karena 1 aspirasi punya 1 kategori).
• Kategori hasMany Aspirasi (karena 1 kategori bisa berisi banyak aspirasi).

11. Local Scope pada Model

Local Scope memungkinkan kita untuk mendefinisikan kumpulan kondisi query yang sering digunakan berulang kali, sehingga sintaks penulisan di Controller menjadi lebih rapi dan ekspresif.

Contoh 1: scopeStatus()

Sederhana 
// Di dalam Model Aspirasi.php
public function scopeStatus($query, $status)
{
    return $query->where('status', $status);
}
❌ Tanpa Scope: Aspirasi::where('status', 'Menunggu')->get();
✅ Menggunakan Scope: Aspirasi::status('Menunggu')->get();

Contoh 2: scopeMilikPerwalian()

Kompleks (Relationship Query) 
// Di dalam Model Aspirasi.php
public function scopeMilikPerwalian($query, $waliId)
{
    return $query->whereHas('pelapor', function ($q) use ($waliId) {
        $q->where('wali_id', $waliId);
    });
}

Tujuan Scope Ini: Membatasi agar pengguna bertipe Wali Kelas hanya dapat melihat daftar aspirasi yang dikirimkan oleh siswa-siswa yang berada di bawah perwaliannya. 

// Di Controller Wali Kelas:
$aspirasiSiswa = Aspirasi::milikPerwalian($waliId)->get();
